# 卡片選擇絕不提前複習；它保護排程器

**背景。** Trigger 會在隨機的閒置窗口浮出卡片，但 FSRS（為了 Anki 相容性而選的排程器）假設卡片是在接近到期時間時被複習。提前複習尚未到期的卡片，會把不按排程的資料餵給排程器，削弱間隔效果。然而產品前提又是要*利用*等待時間，所以大多數 trigger 都顯示「沒有東西」同樣是失敗。

**決策。** 每次 Trigger 發生時，Learning Engine 依嚴格順序選擇：(1) 真正到期的卡片；否則 (2) 在每日新卡上限內，引入新的/未看過的卡片；否則 (3) 顯示中性的 idle/stats 狀態。它絕不把尚未到期的卡片提前拉出來。這透過新卡引入來利用等待時間，同時保持每個排程間隔的誠實性。

**後果。** 如果 deck 很小或到期卡很少，有些等待時段合理地會顯示 idle 狀態；這是預期行為，不是 bug。需要每日新卡上限，以避免在忙碌的一天把整副 deck 全部倒給使用者。選 FSRS 而不是 SM-2 是承接「Anki-compatible」目標；未來更換排程器會是另一個更大的獨立決策。
